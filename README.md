## 🚀 How to Deploy to GitHub & GitHub Pages

### Method 1: Upload via GitHub Web (Zero CLI Required)
1. Go to [GitHub New Repository](https://github.com/new).
2. Set **Repository name** to `wedding-affairs` and choose **Public**.
3. Click **Create repository**.
4. On the next page, click **"uploading an existing file"**.
5. Drag and drop all the files from this folder (`index.html`, `js/`, `css/`, `audio/`, `images/`, `vercel.json`, `README.md`) into the browser.
6. Click **Commit changes**.
7. **Enable GitHub Pages**:
   - Go to repository **Settings** → **Pages** (in the left sidebar).
   - Under **Build and deployment** → **Branch**, select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
   - Your website will be live in ~1 minute at:
     ```
     https://<your-github-username>.github.io/wedding-affairs/
     ```

### Method 2: Git Command Line (If Git is installed)
```bash
git init
git add .
git commit -m "Initial commit of Wedding Affairs luxury website"
git branch -M main
git remote add origin https://github.com/<your-username>/wedding-affairs.git
git push -u origin main
```

## ⚡ How to Deploy to Vercel (Fastest & Best Performance)

Vercel provides blazing-fast global edge CDN hosting, automated SSL certificates, and optimal streaming for the audio files.

### Option A: 1-Click via GitHub (Recommended)
1. Once your repository is uploaded to GitHub (using the steps above):
2. Log into [Vercel](https://vercel.com/) (Sign in with your GitHub account).
3. Click **"Add New..."** → **"Project"**.
4. Under **Import Git Repository**, find `wedding-affairs` and click **Import**.
5. In the configuration screen:
   - **Framework Preset**: *Other* (Static HTML)
   - **Root Directory**: `./` (leave default)
6. Click **Deploy**.
7. In ~15 seconds, Vercel will give you a live global production URL:
   ```
   https://wedding-affairs.vercel.app
   ```
8. *Any future updates pushed to your GitHub repository will automatically update the live Vercel site instantly!*

### Option B: Deploy via Vercel CLI
If you have Node.js installed on your computer:
```bash
npm i -g vercel
cd wedding-affairs
vercel
```
Follow the prompts (accept default settings) and your site is live immediately!
